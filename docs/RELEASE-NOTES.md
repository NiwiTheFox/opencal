# OpenCal 0.4

## 0.4 usability changes

Single-value maps use a compact editable card with explicit units, original/current values and raw storage details. SVRL and SVBL have separate navigation shortcuts. Sidebar size is constrained initially and remains user-resizable; the map tree has scrollbars. Global font override removed so titles and scalar values use their intended sizes. The stock BIN independently confirms SVRL 5300 rpm and SVBL 2375 mbar. 46 tests and the Tk smoke workflows pass.
